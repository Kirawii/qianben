# Android 界面改版 · 0.1.2

## 审查与方向

原界面使用绿色文字、米色背景和平台默认按钮，五个导航按钮置于顶部。首页指标连续堆叠，事件下面展开全部操作，主次关系弱、按钮占用过多空间。

改版保留钱本名称、绿色、五个导航入口及既有表单字段。方向是清爽、克制的个人财务界面，采用 Android 平台原生 Material 主题与控件；没有新增第三方 UI 包，也不声称使用了 Material 3。设计取舍为低变化、低动效、中等密度（设计变化 4、动效 2、密度 4），不使用装饰动画、照片或图标混搭。

## 统一规范

- 浅色：背景 #F4F6F2、卡片 #FFFFFF、主文字 #213C33、次文字 #64756D、强调色 #28664C。
- 深色随系统：背景 #101B16、卡片 #1B2923、主文字 #E8EEEA、次文字 #B1C1B7、强调色 #A1D7BC。
- 平台 sans 字体；正文 15–16sp、辅助 12–14sp、节标题 18–22sp、净资产 34sp。
- 内容边距 20dp、卡片间距 14dp、卡片圆角 16dp、表单与按钮圆角 12dp；按钮触点至少 48dp，输入框至少 52dp。
- 常规按钮无额外阴影，主提交用强调色，删除和撤销使用危险色；保留原生 Ripple、焦点及系统弹窗。

首页按净资产、消费/现金变动、会计收支、待处理、消费分类分组。现金流细项进入弹窗；月份选择横向排列。导航移到底部，所选入口有背景与文字状态。大金额允许换行，不截断实际金额。

账户与事件独立分组。待确认支持“只看待确认”，分页筛选为空时只说明当前页无记录，不声称全账本没有待确认。确认按钮直接显示；证据、历史、合并拆分和转账进入“更多操作”。修订历史展现最近 100 次接受事实、正常/冲销分录及账本版本，超过此范围的分页后移。

表单按交易类型显示原消费、资产名称和还款目标；无关字段隐藏且不提交残留关联。保留共同字段及既有相对顺序。异步报表和历史页校验页面代次，避免切页后旧响应插入新界面。读取失败提供重试入口。

通知来源多选保存在本机。取消不保存，空选择停止所有新来源采集；只有既有 allowlist 可选。关闭来源不清空先前队列，设置页明确说明上传范围和这一行为。

## 验证边界

采用 Android API 35 模拟器、合成账本进行视觉与交互检查。构建、Lint、真实数据库和仪器测试结果记录在 VERIFICATION.md。其他 OEM、真实支付通知、TalkBack 完整流程及多种物理设备仍需验证。
