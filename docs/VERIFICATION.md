日期：2026-10-06。全部财务数据为合成样例；结果说明本机覆盖的行为，不代表真实通知覆盖率或生产零错误。

- Windows；Go 1.27.1，模块最低版本 1.24。
- Docker PostgreSQL 17.11；独立管理员和 qianben_app 角色。
- Android SDK 35、JDK 17、Gradle 8.14.5、AGP 8.9.2、Kotlin 2.1.20。
- Android 15 / API 35，Medium Phone 模拟器，以只读、无窗口方式运行。

`go test ./... -count=1` 和 `go vet ./...` 通过；开发脚本 `scripts/dev.ps1 test` 实际执行通过。Go 真实数据库测试使用 TEST_ADMIN_DATABASE_URL 与 TEST_DATABASE_URL，没有用内存数据库替代 PostgreSQL。

Android `assembleDebug`、`lintDebug` 通过；`connectedDebugAndroidTest` 的 **2 项仪器测试均通过**。Lint 保留非错误建议，包括同步 SharedPreferences 写入、固定依赖版本有更新及 kapt 可迁移 KSP；未用 baseline 屏蔽错误。minSdk 26 的错误 API 使用已修复。

## 覆盖结果

| 检查 | 实际结果 |
|---|---|
| 金额 JSON 大于 JavaScript 安全整数范围 | 整数字符串无精度丢失；拒绝数值 JSON 和溢出 |
| 借贷模板、信用卡消费、时间边界、非 CNY | 单元测试通过；证据不足保持待确认 |
| 相同 command 重试 | 返回原结果，不重复入账 |
| 两个并发修改同一事件 | 一次接受、一次 409；保留单一当前解释 |
| 待查扣款改为消费 | 旧分录精确冲销；待查余额与未分类现金净额归零 |
| 部分退款、累计超额退款 | 正确冲减；拒绝累计超额 |
| 同一通知投递 20 次 | 仅一份 Observation |
| 同一 episode 的 A→B→A | 保留三份快照，worker 汇集为待确认事件 |
| 两笔同金额消费 | 先保留两笔，不自动按金额合并 |
| 两笔已入账后用户合并 | 多余账务冲销，保留一套效果 |
| 合并后再拆分 | 原整体冲销，子事件金额合计及效果正确 |
| 拆分中非法子事件 | 完整回滚，版本和消费额不改变 |
| 信用卡消费后还款 | 还款不重复计消费，现金变动在还款记录体现 |
| 同一 CSV 重复导入 | 不重复记账；重复 record_id 校验通过 |
| 跨日转账 | 保留每端自己的发生日；关联不生成第三套 Journal |
| 转账关联后改变经济类型 | 被拒绝；可显式解除关联再处理 |
| 跨用户读、直接写 Journal | 均受阻止 |
| 删除完整账本 | 金融证据、修订和分录级联清除，删除日志保留 |
| Android 数据库关闭重开 | 密文证据、固定命令和 episode 序号保留 |
| Android 清除一个账本队列 | 其他账本证据及命令保留 |

## 端到端操作

在模拟器安装 APK，通过本机 API 连接，完成建账本、添加 DemoBank、设置 1000.00 元期初和手动消费 12.34 元。最终首页显示：

- 生活消费 12.34 元；会计费用 12.34 元。
- 现金变动 -12.34 元；外部现金流 -12.34 元。
- 待查余额 0、待确认 0。
- 实际账户余额经 HTTP 查询为 987.66 元。

APK 升级后令牌、账本和期初数据仍可读取，Room 升级及 Keystore 路径正常。额外用 HTTP 将同一消费改为 15.00 元，再恢复 12.34 元，余额仍为 987.66 元，保留冲销历史。

## 备份恢复

对含期初、消费及两次纠错历史的本机数据库执行 `pg_dump -Fc`，恢复至独立 QA 数据库。逐项核对：

1. Entry 数量、借贷净额及按 ID 排序的完整分录摘要一致。
2. Ledger ID 与版本摘要一致。
3. 接受的 EventRevision facts 与 evidence_refs 摘要一致。

演练通过；没有切换或覆盖原运行数据库。此演练没有验证生产 RTO/RPO，也没有证明旧备份中的删除数据会自动消失。

## 未验证与受限能力

真实银行、微信、支付宝通知的可读性、敏感内容遮蔽、厂商后台保活、耗电及采集覆盖尚未完成真机实验。只验证合成通知的服务端合同和模拟器本地队列，不声称实际银行通知测试通过。

公网安全、压力测试、复杂退款分摊、报销批次匹配、正式对账、固定资产折旧/处置/估值及多币种不在本次验收结论中。带既存经济关系的修复采用明确保护及解除流程，未实现自动关系分摊迁移。
