## 尚须完成的软件项

- 通知必要抽取片段及本机原文保留/删除策略；经过真实样本验证的强证据实际账户/经济时间提取与自动维护。
- 强交易证据的资金来源确认与相互冲突处理；默认偏好不作证明的边界和用户确认关系已实现。旧版用户确认不伪造回填新关系，仍可查看原证据历史。
- 可信证据驱动的转账自动闭合、手续费/结算/分期等明确 MVP 关系边界；已有关联的合并拆分分摊迁移。人工候选及未闭合现金流分项已实现。非现金投资购置不能冒用现金转账模板，专用投资购置链路仍未实现。
- 原生支付与银行 CSV 适配、历史消费分类、关联退款后的净消费及排除项视图已实现。通知/账单原币及 CNY 结算的强证据自动抽取。用户确认的原币与最终结算结构已实现。
- 质量统计的真机采集完整性与准确率报告；完整修复关系迁移链。
- 用户显式历史规则重放、进程故障注入和完整固定验收样例。
- 上线前的传输/存储保护、保留期、完整用户与密钥删除、备份到期策略及性能验收。

## 设备与执行限制

用户提供：vivo X90s / Android 16。2026-10-08 查询 ADB 尚无已连接设备。PRD 要求另一种 OEM 与 Android 版本，仍未覆盖。合成通知与模拟器不能替代真实支付、银行通知可读性和后台存活实验。

自动审批审核曾因账户使用额度耗尽而未完成，随后恢复，Android 构建、lint 和 4 项模拟器仪器测试已执行通过。Docker 临时套接字损坏曾中断数据库回归；仅将含两个零字节通信文件的 run 目录整体备份重建，原数据卷完整保留，数据库恢复健康且最终真实 PostgreSQL 回归已通过。构建产物、截图和合成验收凭据保存在忽略的本地文件中，不提交个人数据。
