# PRD MVP Core 补齐台账

需求权威：QianBen_PRD_v0.3.2.md 及用户确认的 D-01 / D-02 / D-03。目标是完成 MVP Core，后移版本单列，不将未验证能力标记为完成。

## 当前补齐

| 要求 | 实现 | 验收状态 |
|---|---|---|
| 分类与账务性质分离 | 描述字段修订沿用既有分录；审计历史保留；分类报表读取最新分类 | 真实 PostgreSQL 回归通过，分录数不增加 |
| 待查款不充作已确认资产 | 返回已确认资产/负债/净资产与待查暂定影响；首页分别展示 | 真实 PostgreSQL 3000 分待查扣款通过；模拟器实际首页展示 950 元已确认净资产及 20 元暂定影响 |
| 报销批次与部分分配 | REIMBURSES 多笔分配、逐笔余款、整批替换/解除和历史 | 真实 PostgreSQL验收通过；模拟器实际保存 40 元分配到 50 元垫付，服务端回读余款 10 元 |
| 先流水后期初 | 期初与已接受阻塞流水在同一事务校验激活 | 真实 PostgreSQL：整批失败回滚、修正重试、历史流水不重记通过 |
| 离线重启可查看 | Room v3 加密 CachedView，身份/地址/请求隔离，缓存优先显示并后台刷新，缓存时间提示 | 最终构建/lint、4 项仪器测试通过；停止 QA API 后实际强制冷启动显示正确缓存及未核验提示；真机待验证 |
| 可解释重复候选 | 金额/币种/方向/实际账户和完整证据簇约束；仅人工确认；搜索范围与歧义提示 | 纯 Go 及真实 PostgreSQL 验收通过，包含多候选歧义、跨用户拒绝、合并后完整簇冲突；Android 构建/lint 通过 |
| 数据新鲜度与异常统计 | 账户三种时间分别展示；同版本处理依据/待确认原因及首次创建年龄 | 真实 PostgreSQL 正确口径、异常年龄、CSV 依据及跨用户拒绝通过；模拟器实际质量页面验证通过 |

Android 缓存仅在网络 IOException 时回退；HTTP 鉴权错误不能回退，401/403 清理该身份的缓存。成功写入会使有关账本视图缓存失效。离线显示不是已同步或已对账声明。

## 尚须完成的软件项

- 通知本地结构化解析、默认最小化上传；经过真实样本验证的强证据实际账户/经济时间提取与自动维护。
- 时间化资金来源偏好、逐笔交易证据及用户确认的独立关系；冲突处理。
- 转账闭合候选、手续费/结算/分期等明确 MVP 关系边界；已有关联的合并拆分分摊迁移。
- 原生支付与银行 CSV 适配、历史消费分析、原币金额与最终 CNY 结算结构化证据。
- 质量统计的真机采集完整性与准确率报告；完整修复链与超过 100 次历史的分页。
- 用户显式历史规则重放、进程故障注入和完整固定验收样例。
- 上线前的传输/存储保护、保留期、完整用户与密钥删除、备份到期策略及性能验收。

## 设备与执行限制

用户提供：vivo X90s / Android 16。2026-10-08 查询 ADB 尚无已连接设备。PRD 要求另一种 OEM 与 Android 版本，仍未覆盖。合成通知与模拟器不能替代真实支付、银行通知可读性和后台存活实验。

自动审批审核曾因账户使用额度耗尽而未完成，随后恢复，Android 构建、lint 和 4 项模拟器仪器测试已执行通过。Docker 临时套接字损坏曾中断数据库回归；仅将含两个零字节通信文件的 run 目录整体备份重建，原数据卷完整保留，数据库恢复健康且最终真实 PostgreSQL 回归已通过。构建产物、截图和合成验收凭据保存在忽略的本地文件中，不提交个人数据。

## PRD 后移版本

正式账单覆盖证明与对账（v0.5）；资产折旧/处置/估值（v0.7）；AI/OCR（v0.8）；完整多币种。它们不作为当前 MVP 已完成能力。
