# 功能缺口 · 2026-10-08

0.1.1 已补充月度资产负债/净资产、会计收入/结余、生活分类、商户规则查看撤销和实际余额检查。以下仍未实现，不视为已完成。

## 优先补齐

- 用户选择各通知来源及真机实验报告；两种 Android 版本、两种 OEM，支付与银行来源。需要实际设备和真实授权样本，合成测试不能代替。
- 通知端结构化解析与最小化上传；当前只筛选必要财务通知，财务正文仍上传到服务端解析，尚未满足结构化默认上传的完整目标。
- 报销到账与原垫付的 REIMBURSES 分摊关联、剩余应收及批次处理；现有会计模板只维护总应收。
- 可解释的跨来源重复候选与转账闭合候选。目前由用户确认合并和转账关联，不按金额自动判定同一事件。
- 异常年龄、账户数据新鲜度、自动/人工处理统计；当前只有待确认数和暂记余额。
- 逐事件修订和冲销历史的用户界面；底层历史保存，当前证据界面不足以展示完整修复链。
- 微信、支付宝及银行原生导出格式适配；当前 CSV 是明确的统一合同格式。
- 通知上传范围说明、保留期管理、正文清理及备份到期策略；公开上线前完成。

## 复杂修复及后续版本

- 带退款、报销分摊关系的合并拆分和自动迁移；当前保护关系，避免错误修复。
- 正式账单对账、覆盖范围证明和差异关闭（PRD v0.5）。余额比较不替代正式对账。
- 固定资产折旧、处置、估值、多币种，依原确认后移。
- AI/OCR、外部任务租约、预计算投影，只有实际需要时引入。
- 公网账户注册/恢复、RLS、安全审计、负载及灾备验证；目前定位个人本地开发试用。
