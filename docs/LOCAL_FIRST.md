# 本机优先架构与迁移台账

用户已明确要求安装后独立使用。此决定取代旧 TDD 中“PostgreSQL 是所有使用方式唯一账务权威”的部署前提：本机模式以手机内的事务存储为权威，服务器模式仍以 PostgreSQL 为权威。两者目前是隔离的账本，不会自动同步，也不会把服务器数据覆盖成本机数据。

## 运行边界

APK 打包现有 Go domain/accounting 与新增 ondevice 事务入口，编译为 WebAssembly，由系统 WebView 的隔离运行时执行。界面仍是 Kotlin 原生视图；WebView 不展示网页、不监听本机端口、不加载远程脚本。网络加载被禁止，仅允许内置 HTML、与 Go 编译器配套的 wasm_exec.js 和 engine.wasm 三份资源。Go 及运行时许可证随包保存。手机不需要安装 Go、PostgreSQL、Docker 或启动电脑服务。

每次调用解码加密存储中的完整状态，在副本上执行，成功才返回下一状态与响应；失败不返回可提交状态。Android 串行调用本机引擎，使用 Keystore AES-GCM 加密下一状态，在 Room 的 SQLite 单条事务提交状态、不可变分录、事件历史及命令收据，再返回界面。进程重启从持久状态恢复；相同 command_id 相同内容返回原收据，不同内容拒绝。金额仍用整数分字符串及 Go 溢出检查。分类变化沿用原分录；财务变化保留原分录、精确冲销和替换。

当前状态存放于 CachedView 的独立键 ondevice-state-v1、独立 ledger 标记 @ondevice，不受远程身份缓存失效或单个账本缓存清理影响。账本删除通过本机引擎修改完整状态。名字虽然复用既有存储表，本机状态是权威持久数据，不能作为可丢弃的缓存清理。未来存储升级须将它迁移到独立表，并保证密文、命令收据和历史不丢失。

## 当前迁移范围

- 已加入：首次建账、CNY 资产/信用卡账户、期初、普通消费和收入、用途待查收支、转账两端、垫付、固定资产购置、信用卡还款、修订冲销、余额和月度基础报表、账本删除。
- 通知：新增本机观察存储和 ACK；默认保留待确认，不从通知发布时间推断经济时间或实际账户。新来源快照不能静默覆盖用户接受的账务。
- 修订历史已加入时间、账本版本、原分录/冲销/替换及沿用账务的客户端合同，仍须实际 UI 验收；早期开发状态缺少的审计时间标为空，不从经济时间补造。
- 尚需移植并验收：退款与报销关联容量、转账关联和闭合、合并/拆分、证据完整 UI 合同、CSV、原币结算专项、资金偏好关系、余额检查、商户规则、质量及历史分析等。未经移植的操作明确拒绝；不能称为与服务器版完整等价。
- 云端备份/同步、设备迁移、完整用户和密钥删除、性能及双真机验收尚未完成。系统 WebView 的 WebAssembly 支持和冷启动须真机验证。

## 构建与验证

Android preBuild 自动使用工作区便携 Go（存在时）或 PATH 的 Go 构建引擎，并从同一 GOROOT 复制配套 JS 运行时及许可证。生成内容位于 android/app/build/generated/device-assets，不提交二进制。Go SDK 要支持 js/wasm，当前开发环境使用 Go 1.27.1。

Go 测试应验证：无数据库建账、先流水后期初、固定命令重试、分类不改账、财务修订保留冲销、过期修订拒绝、历史与不确定信息不入账、无效状态与未移植关系不提交。

Android 仪器测试应验证实际打包的 WASM、WebView 启动、无令牌和服务的建账/消费/报表、重复提交以及加密持久化。首次安装、飞行模式、进程强制停止后重新打开的实际 UI 验收仍须独立记录，不能用 Go 单元测试代替。

2026-10-10 验收：最终源码的 Go 真实 PostgreSQL 全套回归/vet 与本机引擎专项通过；Android 构建/lint 及 API 35 模拟器 7 项仪器测试通过，0 失败/错误/跳过。新增仪器测试使用 APK 内 Go WASM 无服务器建账、设置 100 元期初、保存 12.34 元消费、固定命令重试，回读余额与净资产 87.66 元、消费 12.34 元，随后清理合成账本。实际界面另外关闭模拟器网络（飞行模式、Wi-Fi 和移动数据），不填地址/令牌完成建账、账户、期初和消费；最终 APK 强制停止并重新打开仍显示 87.66 元净资产和 12.34 元消费。只测试模拟器与合成数据，不声称 vivo Android 16 真机或全部本机迁移功能已通过。修订历史的 UI、真实通知采集和本机更新冲突仍须后续专项验收。
